## Что важно понимать

### threading
`threading` использует потоки внутри одного процесса. В CPython потоки ограничены GIL, поэтому для тяжелых CPU-вычислений они обычно не дают реального ускорения. Зато потоки хорошо подходят для задач ожидания: сетевые запросы, чтение файлов, работа с внешними сервисами.

### multiprocessing
`multiprocessing` запускает несколько отдельных процессов. У каждого процесса свой интерпретатор Python и свой GIL, поэтому этот подход подходит для CPU-bound задач: тяжелые вычисления, обработка больших массивов данных, математические операции.

### asyncio
`asyncio` работает в одном потоке и использует кооперативную многозадачность. Он не ускоряет тяжелые вычисления сам по себе, но отлично подходит для большого количества сетевых запросов, где программа часто ждет ответ от сервера.

## Вывод

Для вычислительной задачи лучше всего подходит `multiprocessing`, так как он реально распределяет работу между несколькими процессами. `threading` в Python ограничен GIL и не дает значительного ускорения при CPU-bound задачах. `asyncio` не предназначен для ускорения вычислений, потому что асинхронность помогает там, где программа ждет ввод-вывод.

Для парсинга сайтов ситуация другая. HTTP-запросы являются I/O-bound задачей, поэтому `threading` и `asyncio` подходят хорошо. `asyncio` часто оказывается наиболее эффективным и легковесным вариантом, потому что не создает отдельный поток или процесс для каждой задачи.


## Как узнать DATABASE_URL

В проекте лабораторной работы 1 подключение было настроено через файл `.env`.

В коде это видно здесь:

```python
# app/core/config.py
database_url: str = Field(alias="DATABASE_URL")
```

Формат строки подключения:

```env
DATABASE_URL=postgresql://postgres:пароль@localhost:5432/название_базы
```

Пример:

```env
DATABASE_URL=postgresql://postgres:1234@localhost:5432/travel_db
```


## Исправление под Python 3.13

В этой версии не используется `psycopg2-binary` и `asyncpg`, потому что на Python 3.13 они могут пытаться собираться из исходников и падать при установке.

Для подключения к PostgreSQL используется:

```text
psycopg[binary]
```

В async-версии HTTP-запросы выполняются асинхронно через `aiohttp`, а сохранение в PostgreSQL вынесено через `asyncio.to_thread`.
